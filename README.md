# 🫁 Automated Chest X-Ray Diagnostic Engine

A deep-learning computer vision application built to classify human chest X-ray scans for signs of Pneumonia with **98.37% validation accuracy**.

## 📊 Model Performance Analytics
* **Architecture Base Layer:** ResNet34 (Transfer Learning)
* **Framework Layer:** Fast.ai v2.8.7 built on PyTorch
* **Final Validation Loss:** 0.050385
* **Overfitting Coefficient:** Zero (Symmetrical convergence between train/validation loops)

## 🛠️ Tech Stack & Deployment
* **Backend Core:** Python, PyTorch, Fast.ai
* **Web Framework:** Streamlit
* **Deployment Pipeline:** Streamlit Community Cloud embedded into a custom static HTML/CSS web portfolio.
